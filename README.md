# Kiaan Technology — E-Commerce Business Operating System

A modern, production-grade **E-Commerce Business Management Operating System** built with React, Vite, Tailwind CSS, Lucide Icons, Recharts, and Express.

---

## 🌟 Key Features

* **Interactive Commerce Dashboard**: Hero greeting, floating mini stats, Active Summer Campaign, 5 KPI metrics, live Flash Sale countdown timer, circular categories, Store Health score gauge, recent orders, and best seller showcases.
* **Products Suite**: Multi-attribute filtering (category, brand, price, status, stock), Grid/List view toggle, multi-step Add Product with live preview modal, and Product Details with sales graphs.
* **Categories, Collections & Brands**: Complete departments directory, curated seasonal lookbooks, merchant brands, and customer review moderation.
* **Orders & Reverse Logistics**: Status pipeline tabs, full tracking step timeline, and printable commercial tax invoice generator.
* **Customers & Cohort Segmentation**: VIP, New, Returning, and At-Risk customer cohorts with 1-click marketing blast triggers.
* **Marketing & Promotions**: Multi-channel campaigns with ROAS, discount coupons with 1-click code copying, and affiliate partner network.
* **Analytics & Intelligence**: Gross revenue vs profit margins, category contribution pie charts, cohort retention curves, and 1-click AI actions.
* **Settings & Access Control**: Store profiles, UPI QR / Razorpay / COD payments, shipping courier rules, and RBAC team permissions (Admin, Manager, Staff).

## 🚀 Getting Started

### 1. Installation
```bash
# Clone the repository
git clone https://github.com/ashilata62/E-Commerce-Management-Platform.git
cd E-Commerce-Management-Platform

# Install client dependencies
cd client
npm install
```

### 2. Run the Application
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
